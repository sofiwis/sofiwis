## 💡 Resumen Rápido del Proyecto

**ESENCIA** no es una página web estática cualquiera: es una **aplicación web moderna completa** compuesta por dos partes principales:

1. **La Vitrina Pública (Frontend):** Lo que ven los clientes cuando entran al enlace (`/`, `/quienes-somos`, `/productos`, `/portafolio`, `/contacto`). Es elegante, rápida, se adapta a teléfonos móviles y tiene animaciones cuidadas.
2. **El Motor y Almacén (Backend y Base de Datos):** El cerebro que corre en el servidor (`server.js`), recibe las preguntas de los clientes, almacena los proyectos de forma segura en un archivador digital (`SQLite` o `PostgreSQL`) y permite a los administradores gestionar la web desde `/admin`.
